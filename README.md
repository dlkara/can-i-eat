# 먹어도 돼? · can-i-eat

저장한 알레르기 정보와 식품 표시 데이터를 비교해 추천 후보, 성분 제외 검색, 알레르기 카드를 제공하는 웹 서비스입니다.

[기존 배포 사이트](https://meogeodo-dwae-v2-p230-hjlee-20260916.dlkara.chatgpt.site/) · [구현·검증 기록](docs/implementation-record.md) · [Git 이관 기록](docs/git-handoff.md)

## 현재 구현

- 19개 식품 알레르기 저장 및 조건 변경에 따른 추천 갱신
- 직접 함유·제조환경 경고·정보 미확인 구분: 저장 기준과 관련된 경고·미확인 상품은 추천에서 제외
- 홈 추천 최대 3개 및 전체 후보 화면
- 상품명·카테고리 검색과 명시적 제외 조건의 실제 필터 적용
- 출처가 기록된 실제 상품 25개 및 별도로 분리된 가상 테스트 상품 22개
- 원재료·표시 문구·출처·확인일을 확인하는 상품 상세
- 약물·이상반응 입력 기록과 제시용 알레르기 카드
- PC·태블릿·모바일 반응형 화면 및 개복치 캐릭터

HTML/CSS/JavaScript로 구현했으며 입력값은 현재 브라우저의 `localStorage`에 저장됩니다. 로그인·가입 화면은 브라우저 체험 계정입니다. 실제 회원 인증, 서버 API·DB 저장, LLM 검색, 상품 정보 자동 갱신은 구현되어 있지 않습니다.

추천 후보와 검색 결과는 공개 표시 기록을 비교한 결과입니다. 섭취 가능 판정이나 무함유 인증을 제공하지 않습니다. 제조환경 정보가 없거나 관련 항목이 확인 범위 밖인 경우 미확인으로 유지합니다. MadeGood 3개는 미국 표시 기준이며 국내 수입 라벨은 미확인입니다. 실제 상품의 확인일과 원문 링크는 `dist/products.js`에 있습니다.

## 로컬 실행

Git과 Python 3가 필요합니다. 실행 시 별도의 빌드나 패키지 설치는 필요하지 않습니다.

```sh
git clone https://github.com/dlkara/can-i-eat.git
cd can-i-eat
python3 -m http.server 4173 --directory dist
```

브라우저에서 http://127.0.0.1:4173/#home 을 엽니다. 브라우저와 주소가 달라지면 저장 공간도 달라집니다. 기본으로 표시되는 밀·복숭아 및 약물 기록은 체험용 초기값입니다.

## 검증

Node.js가 설치된 환경에서 프로젝트 루트에서 실행합니다. 데이터·필터 검사는 외부 패키지가 필요하지 않습니다.

```sh
node scripts/verify-data.mjs
node --check dist/app.js
node --check dist/products.js
```

GitHub 이관 시 실제 데이터·필터 검사 35건과 JavaScript 문법 검사를 실행했습니다. 검사에는 상품 수·출처 기록, 직접 함유·제조환경 제외, 항목별 미확인, 밀·복숭아 동시 기준 후보 2개, 대두·아황산류 제외 및 가상 모드 분리가 포함됩니다. 결과 파일은 무시되는 `artifacts/qa/`에 생성됩니다.

이전 단계의 브라우저 검사와 화면 확인 결과는 날짜별 구현 기록에 남아 있습니다. 최초 브라우저 119건은 2026-10-08 당시 버전에 대한 결과이며 현재 디자인에서 전체 재실행한 결과가 아닙니다. `scripts/verify.mjs`와 `scripts/capture.mjs`에는 기존 작업 환경의 Playwright·Chrome 절대 경로가 남아 있으며 실행 전에 환경 경로와 최신 화면·상품 기대값을 맞춰야 합니다. 이번 GitHub 이관에서 브라우저 검사를 재실행하지 않았습니다.

## 파일 구성

| 경로 | 역할 |
| --- | --- |
| `dist/index.html`, `dist/styles.css` | 화면 틀과 반응형 디자인 |
| `dist/app.js` | 저장 상태, 추천·검색·경고 분류, 화면 동작 |
| `dist/products.js` | 실제 상품 표시 정보와 근거 링크 |
| `dist/assets/mascot/` | 사이트에 선택한 캐릭터 이미지 3개 |
| `scripts/verify-data.mjs` | 데이터·필터 검사 |
| `docs/implementation-record.md` | 사용자 결정과 AI 구현·검증의 구분 기록 |
| `docs/wheat-snack-review-2026-10-10.md` | 제공된 과자 이미지 후보의 출처 검토 기록 |
| `.openai/hosting.json` | 기존 Sites 프로젝트의 정적 배포 설정 |

구현 기록의 개인 PC 문서 경로와 `artifacts/qa/` 경로는 당시 로컬 자료 참조입니다. 해당 원본 문서·캡처·배포 로그는 이 저장소에 포함되어 있지 않습니다. 공개된 상품 원문 링크는 기록과 데이터 파일에서 확인할 수 있습니다. 상품 원본 표시 이미지는 링크로 제공하며 저장소에 복제하지 않았습니다.

## 작업 이어가기

작업 전 `git pull --ff-only`로 최신 버전을 받습니다. 수정 후 데이터·문법 검사를 실행하고, UI 변경은 로컬 화면에서 추가 확인한 뒤 커밋·푸시합니다. GitHub 푸시는 Sites 재배포를 자동으로 실행하지 않습니다. 기존 사이트 배포는 별도 절차로 관리합니다.
